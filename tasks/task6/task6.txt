1. Number Transformation
Write a function that accepts an integer and returns a new number formed by replacing every even digit with
0 and every odd digit with 1.
Example: 583246 → 101010
code:
def transformation(num):
    new=""
    for i in str(num):
        if int(i)%2==0:
            new+="0"
        else:
            new+="1"
    print(new)

2. Digit Frequency Analyzer
Write a function that accepts a number and a digit. Return how many times that digit appears in the number.
Example: Number = 1223122, Digit = 2 → 4
code :
def freq_analyzer(number, digit):
    count = 0
    for i in str(number):
        if i == str(digit):
            count += 1
    print(count)

freq_analyzer(1223122, 2)  # 4

4. Number Reordering
Write a function that accepts an integer and returns the number formed by arranging its digits in ascending
order.
Example: 583214 → 123458
code:
def num_reorder(num):
    digits=str(num)
    new=""

    for i in range(0,10):
        for j in digits:
            if int(j)==i:
                new+=j
    return int(new)

print(num_reorder(6105321))

Write a function that accepts the number of electricity units consumed and calculates the bill using these
slabs:
• First 100 units: ■2 per unit
• Next 100 units: ■3 per unit
• Units above 200: ■5 per unit
Return the total bill amount. Apply each rate only to the units in its slab.
code :
def electricitybill():
    units=int(input("enter the unit consumed: "))

    if units <=100:
        bill=units*2
    elif units<=200:
        bill=100*2+ (units-100)*3
    else:
        bill=100*2+ 100*3 + (units-200)*5

    print(f"The total bill amount is {bill}")

8. Armstrong Number Range
Write a function that accepts a number and checks whether it is an Armstrong number. Then write another
function that displays all Armstrong numbers from 1 to a given limit.
Example: For limit 500, display 1, 153, 370, 371, 407.
code :
def armstrong_range(limit):
    for i in range(1,limit+1):
        total=0
        for j in str(i):
            cube=int(j)**3
            total+=cube
        if total==i:
            print(i)

armstrong_range(500)

10. Time Converter
Write a function that accepts a total number of seconds and returns the equivalent hours, minutes, and
remaining seconds.
Example: 3,725 seconds → 1 hour, 2 minutes, 5 seconds.
Challenge: Break each problem into clear steps and test your function with at least two different inputs
code:
def convert_seconds(total_seconds):
    hours = total_seconds // 3600
    minutes = (total_seconds % 3600) // 60
    seconds = total_seconds % 60
    print(f"{hours} hour(s), {minutes} minute(s), {seconds} second(s)")
