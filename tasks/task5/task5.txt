1.Replace Vowels with *
Sample Input: "education"
Sample Output: "*d*c*t**n"

code:
====
string="education"

vowels="aeiou"

new=""
for i in string:
    if i in vowels:
        new=new+"*"
    else:
        new=new+i


print(new)

4.Compress a String
  Sample Input: "aaabbccccdaa"
  Sample Output: "a3b2c4d1a2"

string="aaabbccccdaa"
new=""
for i in string:
    count=string.count(i)
    if i not in new:
       new=new+i+str(count)

print(new)

5.Expand an Encoded String
Sample Input: "a3b2c4"
Sample Output: "aaabbcccc"

code:
====
string="a3b2c4"
new=""
letter=""
for i in string:
      if i.isalpha():
          letter=i
      elif i.isdigit():
          digit=int(i)
          new+=letter*digit
print(new)

8.Check Neon Number
  Sample Input: 9
  Sample Output: Neon Number
  Sample Input: 12
  Sample Output: Not a Neon Number

 code:
 =====
num=int(input("enter the number: "))
square=num**2
total=0
for i in str(square):
    total=total+int(i)

if total==num:
    print(f"the number {num} is a neon number.")
else:
    print(f"the number {num} is not a neon number.")
