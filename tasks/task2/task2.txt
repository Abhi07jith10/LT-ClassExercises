#1.Write a program to print all numbers between 1 and 100 that are divisible by 7 using a while loop.

i=1

while i<=100:
    if i%7==0:
        print(i)
    i=i+1

2.Write a program to print all numbers between 1 and 100 that are divisible by both 3 and 5 using a while loop

i=1

while i<=100:
    if i%3==0 and i%5==0:
        print(i)
    i+=1

3.Write a program to print all numbers between 1 and 50 that are not divisible by 5 using a while loop.

i=1

while i<=50:
    if i%5!=0:
        print(i)
    i+=1
